API 文档

调用本站 API：快速讲义

01

准备访问密钥

在请求头中使用管理员分配的访问密钥，并只保存在服务端环境变量中。

Authorization: Bearer <访问密钥>
02

发送聊天请求

本站兼容 OpenAI Chat Completions 协议，模型名按部署配置填写。

curl https://your-onr.example.com/v1/chat/completions \
  -H "Authorization: Bearer <访问密钥>" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.8-max","messages":[{"role":"user","content":"你好"}]}'
03

读取响应与用量

非流式响应会在 usage 字段返回输入、输出、缓存和总 Token。

{"usage":{"prompt_tokens":67,"completion_tokens":91,"total_tokens":158}}
04

使用流式响应

设置 stream: true 后读取 SSE 的 data: 行，收到 [DONE] 后结束。

{"model":"qwen3.8-max","stream":true,"messages":[...]}
05

错误处理

401 表示密钥无效，429 表示限流或余额不足，5xx 表示上游或网关暂时不可用。建议指数退避重试。

06

安全实践

不要在浏览器、日志或客户端代码中暴露密钥；为不同应用分配独立密钥并定期轮换。
